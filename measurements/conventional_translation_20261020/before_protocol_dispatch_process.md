# Actual numerical preparation and missing protocol dispatch

The current preparation path does not dispatch the saved SRFP or DNN native
word. Python keeps their tuples as class attributes, while its constructor
calls the same `prepare N` command. Native preparation takes N alone, without
a structure or protocol argument. `kind` is consumed only when naming the
returned reports in `read_prepared`.

The executed Y payload calls `arithmetic_step` on one resident diagram. That
step applies controlled modular additions to build the entire square-minus-self
function across the retained nontrivial residue family. The residual-zero
projection occurs only after all arithmetic rows complete. This accounts for
the intermediate-state growth observed before any point or factor is read.
It does not establish the requested complete SRFP/DNN preparation.

The two companion native symbolic diagrams use the words read directly from
the saved definitions, through IMSCRIBr wiring and its existing renderer:

Their wiring is a separate view from the source dispatch. These diagrams do
not demonstrate that either word acted on the numerical state.

The actual200-bit,20-second CPU profile is retained in
`G-mOMonadOS/measurements/conventional_translation_20261020/flatten_profile/`.
The symbolic rebuild has byte-identical executable `.text` to the profiled
stripped image. `before.symbolized.json` maps file offsets to the rebuilt
symbols using the matched ELF section addresses. The principal sampled work
is diagram interning, reclamation, support metadata and partition traversal.
This local overhead and the expanding intermediate representation are distinct
observations; optimizing one does not demonstrate flat total preparation.

Sources, native words and diagram generation are bound in
`process_diagram_binding.json`; `render_process.py` reproduces the diagrams.
The full requested numerical state and exact896-bit factor return remain
unfinished. A protocol name, word rendering, closed carrier or post-production
certificate cannot stand in for a numerical operation acting during preparation.
