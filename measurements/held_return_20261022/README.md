# Native held membrane return

`idempotent_moment N --hold STEPS RETURN.json` compiles the N-only carrier, executes retained Y steps and writes its open return. `idempotent_moment --resume RETURN.json STEPS NEXT.json` imports the same shared state and continues it without source preparation. The input in this execution is the retained random balanced 200-bit control, supplied without its generator reference factors.

`fresh200/held32.json` is the native return after 32 steps. `held64.json` resumes it for 32 more. `held96_direct.json` resumes held32 for 64 steps; `held96_segmented.json` resumes held64 for 32. `segmentation.exit` is zero and `segmentation.compare` is empty: cmp establishes byte-for-byte equality of the complete two 96-step records. `checkpoints.sha256` binds them. Their report files retain per-invocation clocks and cumulative Y, logical-contraction and copy-return counts. The shared object includes complex coefficients and sparse support, all tensor/source/protocol banks, compacted incidence, pending queue/versions, Y program/counters, SIC frame and exact dual, native graphs, phase/engagement operators, moment operator, source forms and self-model.

The initial preparation is 85.754716475 seconds. Initial 32-step transformation is 0.025037599 seconds and serialization 15.737260346 seconds. The 32→64 transformation is 0.0024199 seconds and serialization 14.793282547 seconds; external lifetime is 19.38 seconds including loading. These are held-state clocks, not factor-readout clocks. All native diagnostic runs use 2 GiB virtual memory and a 64 MiB stack, with their exact external limits and exits in process records. At 96 steps the carrier still has 100,100 open internal coordinates; no divisor is emitted.

Source-sized semantic checks also compare save/resume with uninterrupted complex contraction and reject a corrupted incidence map. Logs are ../held_return_semantics_20261022.log and ../held_return_semantics_final_20261022.log. The original serialized bank compaction defect is repaired: incidence is remapped with flattened surviving roots/scopes, rather than retaining removed-bank indices.

The Cargo path POINT_CARRIER_CONTINUATION_FILE validates and bakes a held return. It is exclusive with POINT_CARRIER_SOURCE_FILE. Typed runtime metadata preserves progress and protocol banks. This remains the diagnostic point_carrier_probe; the separate evaluated final-switch path still requires proper factor/product closure. Static compilation and its later checks retain their own logs, bindings and clocks.
